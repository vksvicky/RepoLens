# Support

## How to get help

| Need | Where |
|------|--------|
| Bug in docs/playbooks/CLI | [GitHub Issues](../../issues) — Bug report template |
| Feature idea | [GitHub Issues](../../issues) — Feature request template |
| How to run reviews today | [using-playbooks.md](./using-playbooks.md) |
| Languages / tools / AI keys / CVE / local learning | [faq.md](./faq.md) |
| Security vulnerability in RepoLens | [SECURITY.md](./SECURITY.md) — private report only |
| Roadmap / what’s implemented | [phases.md](./phases.md) |

## What we don’t offer (yet)

- Paid support or SLAs  
- Guaranteed vulnerability discovery in third-party repos  
- Hosted SaaS scanning  

Community best-effort support only until maintainers announce otherwise.
