# Phase 6.1 Trivy + Checkov Plugins Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans.

**Goal:** Add optional `trivy` and `checkov` scanner plugins (install + run + merge Issues) matching gitleaks/semgrep/osv patterns.

**Architecture:** New adapters under `src/repolens/scanners/`; pin Trivy native archives with SHA-256; Checkov via pip venv (like Semgrep); pure JSON parsers unit-tested with fixtures; wire into `runner.py` + `plugins.py`; feed a short scanner evidence block into deep LLM prompts.

**Tech Stack:** Python 3.11+, existing plugin download helpers, pytest.
