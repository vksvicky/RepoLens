# Phase 6.8 PR suggested-fix UX (design)

**Status:** Approved 2026-08-06 — scope **C without** `gh`/API PR review comments  
**Umbrella:** [phase-6.x §6.8](../../design/phase-6.x-scanner-depth-ci-gates-and-credibility.md)

## In scope

| Item | Notes |
|------|--------|
| `repolens pr-summary` | From FindingReport JSON → PR Markdown |
| `$GITHUB_STEP_SUMMARY` | Action writes summary after review |
| Critical/High suggested fixes | title, file:line, recommendedFix, fenced codeExample |
| Workflow commands | `::error` Critical, `::warning` High (file/line when safe) |
| Docs recipe | `ci.md` |

## Out of scope

- PR review comments via `gh` / GitHub API  
- Auto-commit / Dependabot-style apply  
- Bitbucket/GitLab annotations (docs may note GitHub-first)

## Caps

- Default: include Critical + High only in suggested-fix section (Medium/Low counts in tally only)
- Truncate long code examples (~40 lines) with note
- Annotation count capped (e.g. 20) to avoid log spam
