# Phase 6.7 Suppressions & local feedback (design)

**Status:** Approved scope **B** (2026-08-06)  
**Umbrella:** [phase-6.x §6.7](../../design/phase-6.x-scanner-depth-ci-gates-and-credibility.md)

## Scope B

| In | Out (this slice) |
|----|------------------|
| `.repolens-ignore` (stableId / file+category) | Critical self-consistency second pass |
| `#` / `//` `repolens:disable-next-line` + block form | Cloud feedback upload |
| Honored in fail-on + SARIF; MD **Suppressed** section | Feeding calibrations from thumbs |
| Thin `repolens feedback down` → ignore entry | |

## Rules

1. Suppress **after** `stamp_issue_ids`, **before** summary recount / Markdown / SARIF / fail-on.
2. Inline disable applies to **llm** and **heuristic** only; scanners need an ignore entry (or tool-native suppress).
3. Ignore entries require `reason`; optional `expires` (ISO date); expired = inactive.
4. Never silently drop scanner Criticals without an explicit ignore match.

## File format (`.repolens-ignore` at project root)

TOML:

```toml
[[ignore]]
stableId = "…"
reason = "false_positive"  # or wont_fix | accepted_risk | other
note = "optional"
expires = "2027-01-01"     # optional

[[ignore]]
file = "src/foo.py"
category = "sec.injection"
reason = "wont_fix"
```

## Inline

- `# repolens:disable-next-line` / `// repolens:disable-next-line` → next line
- `# repolens:disable` … `# repolens:enable` (same comment style) → line range
