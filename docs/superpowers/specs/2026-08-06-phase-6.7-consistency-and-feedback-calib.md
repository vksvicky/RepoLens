# Phase 6.7 remainder — Critical consistency + feedback calibrations

**Status:** Implementing (2026-08-06)  
**Depends on:** Scope B suppressions (shipped)

## Critical / High self-consistency

Config (`[deep]`):

| Key | Values | Default |
|-----|--------|---------|
| `critical_consistency` | `off` \| `heuristic` \| `llm` | `off` |
| `critical_consistency_include_high` | bool | `false` (Critical only) |

- **heuristic:** after location verify, LLM/heuristic Critical (optional High) with `locationVerified=false` → demote one severity band + `[unconfirmed: location]` prefix. Non-fatal; scanners untouched.
- **llm:** after first LLM pass, batched confirm JSON for Critical (optional High) LLM rows; `agree` keeps, `demote` drops one band. Failures leave findings unchanged. Temperature already low (0.1).

## Feedback → calibrations

- `repolens feedback down` also appends `.repolens/feedback.jsonl` (local).
- Looks up category/file/title from `.repolens/last_report.json` when possible.
- `apply_feedback_calibrations` (default on when file exists; `[deep].feedback_calibrations = false` to disable):
  - `false_positive` events matching **file+category** → demote matching LLM/heuristic issues to LOW (same style as FP calibrations)
  - **category** with ≥2 FP events → demote matching LLM/heuristic by category
  - Never auto-demote **scanner** findings (use `.repolens-ignore`)
