# Phase 6.10 Optional domain packs (scope B)

**Status:** Approved 2026-08-06  
**Umbrella:** [phase-6.x §6.10](../../design/phase-6.x-scanner-depth-ci-gates-and-credibility.md)

## In scope

1. Pack registry under `repolens.packs` with manifest + playbook + optional heuristics
2. Opt-in: `[packs] enabled = ["azure-sentinel"]` and/or `--pack azure-sentinel`
3. **azure-sentinel** pack: SOAR/Logic Apps/Sentinel playbook + light deterministic checks (tenant IDs, connector secrets, subscription IDs)
4. Docs; core `sentinel` unchanged when pack off

## Out of scope

- Replacing Checkov/ARM-TTK  
- Azure-only product pivot  
- Second domain pack (mobile stub)
