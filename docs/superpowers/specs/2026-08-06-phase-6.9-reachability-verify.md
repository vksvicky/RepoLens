# Phase 6.9 Best-effort reachability & verify (scope B)

**Status:** Approved 2026-08-06  
**Umbrella:** [phase-6.x §6.9](../../design/phase-6.x-scanner-depth-ci-gates-and-credibility.md)

## In scope

1. **SCA metadata** from scanners only: `packageName`, `installedVersion`, `fixedVersion`, `advisoryId` on Issues (Trivy/OSV).
2. **Usage hint** (deterministic): search project source for package name references. Labels: `referenced_in_source` | `no_reference_found`. Never called “reachability”.
3. **Near-duplicate clustering** post-merge: collapse same file+category+normalized title; keep highest severity; note count.
4. **Opt-in verify:** `[deep].verify_findings` / `--verify-findings` — re-check Critical location anchors; annotate unconfirmed; **never** fails report write.
5. **FAQ** honesty: no proprietary reachability graphs.

## Out of scope

- LLM lockfile / “hits production” claims  
- Full sandbox repro generation (C)  
- Snyk-class call graphs
